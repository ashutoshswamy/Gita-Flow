# Gita Flow

![Gita Flow](public/og-image.png)

A spiritual AI application that allows users to seek wisdom and guidance from Lord Krishna, inspired by the teachings of the Bhagavad Gita. Built with Next.js and powered by Google's Gemini AI.

## Features

- Divine wisdom — ask questions and receive guidance in a chat-style conversation
- AI-powered responses via Google's Gemini AI, grounded in Bhagavad Gita teachings
- Google sign-in — Firebase Authentication gates chat access, saving every question and answer to your account
- Multiple named chats — start, rename, and delete chats like any modern chat app
- Persistent history — conversations stored in Neon Postgres, reload automatically on sign-in
- Rate limiting — server-side request limits protect against abuse
- SEO optimized — server-rendered content, structured data, sitemap, robots.txt, Open Graph metadata
